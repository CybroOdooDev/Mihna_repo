Our Core Features

Direct JSON Submission

Sends invoice and credit note data straight to Flick Network's Document API as their own flattened PINT-OM JSON schema - no manual XML file or upload needed.

Peppol Participant Submission

Submits documents against your company's own Flick Peppol "Participant ID" - register once via Flick's dashboard, then enter it in Settings.

Credit Note Support

Submits credit notes straight from Odoo's own Credit Note flow - no extra data entry needed.

Spec-Accurate Payload

Only sends fields Flick Network actually documents for Oman (PINT OM) e-invoicing - nothing invented, including no QR code, which isn't part of their documented schema at all.

One-Click Test Connection

Verify your Flick Network API Key directly from Settings, with a dedicated Test Connection button - before submitting a single invoice.

Oman VAT Format Validation

Validates the Oman VAT format ("OM" + 10 digits) the moment a partner is saved in Odoo, catching bad data before Flick Network ever rejects it at submission.

Status Polling Cron

A scheduled action polls Flick Network for the latest status on every submitted document until it's acknowledged - no manual refresh needed.

Standalone Connector

Works entirely on its own - no dependency on any other Oman e-invoicing module. Installs and configures independently, the same way as our other single-ASP connectors.

Frequent Questions

Does this module build the e-invoice XML itself?

No. Flick Network's API takes their own flattened PINT-OM JSON schema directly - this module builds that JSON from your posted invoice/credit note and sends it to Flick Network, which handles the Peppol/OTA submission on its own platform.

Do I need my own Flick Network account to use this module?

Yes. This module is a connector, not a Flick Network subscription - you'll need your own Flick Network account, registered as a "Participant" on their Peppol network, with an API Key and Participant ID. Enter them in Settings > Invoicing > Flick Network and use the Test Connection button to verify they work before submitting any invoices.
